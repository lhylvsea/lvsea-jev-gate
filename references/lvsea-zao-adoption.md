# Lvsea Zao Adoption

This package adopts the local `lvsea-zao-skill` method rather than copying its entire authoring domain. The retained mechanisms are:

- one root discoverable `SKILL.md`;
- explicit intent, source and trust boundaries;
- trigger regression cases with positive and negative families;
- context-budget measurement and platform-neutral Skill IR;
- secret scanning and evidence-bound public claims;
- feature branch, pull request, immutable versioned Release, discovery and clean-install gates.

The JEV gate itself remains deliberately narrow: it prepares route evidence and waits for a human confirmation. It does not create business artifacts or install candidate Skills.
